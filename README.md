# Fundamentos para programar

El curso inicial de **MyOpenAcademy**: lo que conviene saber antes de cualquier otro curso. Qué es programar, tu ordenador por dentro, la terminal y el editor, los formatos de datos, Git y GitHub, cómo funcionan internet y las aplicaciones, y cómo estudiar y usar la IA. Termina con un proyecto tuyo publicado en internet. Es un curso de **MyOpenAcademy**, la academia de programación libre y gratuita: se puede leer aquí, en GitHub, o instalar en la academia.

**En construcción.**

## A quién va dirigido

A cualquiera que quiera aprender a programar y empiece **desde cero**: no da nada por sabido. Al terminar, entiendes qué es programar y cómo se piensa un algoritmo, manejas tu ordenador, la terminal, el editor, Git y GitHub, lees y escribes los formatos de datos más usados, sabes cómo funcionan internet y las aplicaciones, y tienes **un repositorio propio publicado en GitHub Pages**. Con eso puedes empezar cualquier otro curso de la academia.

El curso no enseña ningún lenguaje de programación: los algoritmos se escriben en **pseudocódigo**, y lo práctico es con herramientas (terminal, Git, Markdown, JSON, YAML, XML y CSV).

## Conviene saber antes

Nada. Es el primer curso de la academia.

## Cómo usarlo

- Empieza por el **[índice](00-indice.md)** o por la **[ruta de aprendizaje](ROADMAP.md)**. Cada módulo tiene teoría, ejemplos, errores típicos, buenas prácticas, ejercicios resueltos en cuatro niveles, una chuleta y preguntas de repaso.
- Puedes seguirlo **en orden** o entrar **por libre** a cualquier módulo: cada uno dice al principio qué conviene saber antes. Las fases 1, 2, 3, 5 y 8 son imprescindibles; la 4, la 6 y la 7, recomendadas.
- Intenta cada ejercicio antes de abrir la solución. Los **retos** del final de cada fase son opcionales.
- El código de los ejemplos y soluciones está en la carpeta `codigo/` de cada fase. Algunas carpetas llevan ficheros como `entrada.txt`, `sesion.txt`, `salida-variable.txt` o `debe-fallar.txt`: sirven para comprobar automáticamente que el código del curso funciona, y puedes ignorarlos.
- Para repasar, la **[chuleta global](99-chuleta-global.md)**, y para los términos, el **[glosario](glosario.md)**, que comparten todos los cursos de la academia.

## Requisitos

Un ordenador con Windows, macOS o Linux y conexión a internet. Lo que hay que instalar (Git, que en Windows trae Git Bash, y Visual Studio Code) se explica paso a paso en el módulo «Instalar programas, variables de entorno y PATH» (fase 2). La fase 1 no necesita instalar nada.
